# LHE7904 UART 接入

在单肌肉采集模式选择 **LHE7904 (UART)**，选择 USB-UART 串口，然后连接并开始录制。
串口固定为 **1,000,000 baud / 8N1 / 无流控**。固件连续发送，无需 START/STOP 命令；停止录制只关闭电脑端口。

配置必须与板上固件一致：默认 **4000 Hz、固件滤波开启、PGA=1**。界面的采样率、滤波选项和 PGA 仅描述接收格式及量程，不会修改设备配置。当前 GUI 支持 1000/2000/4000 Hz；500 Hz 不适合现有 450 Hz EMG 滤波上限，更高采样率超出当前串口吞吐预算。

每个采样点是一个 VOFA+ JustFloat 帧：小端 float32 的 `raw_mV, filtered_mV, time_s`，后接 `00 00 80 7F`，总长16字节。关闭固件滤波时为 `raw_mV, time_s`，总长12字节。4000 Hz 的16字节帧约占640,000 bit/s（含8N1开销）。

后端只把原始电压作为一个 EMG 通道返回，单位已经是 mV，不重复转换增益。固件滤波副本不是第二路肌肉，时间字段也不作为电压记录。实时滤波和包络由现有采集链路计算，EDF 保存原始电压和实际采样率，可继续用于现有离线分析和报告。

EDF 为16位存储，LHE7904 使用完整数字范围 -32768..32767。PGA=1 时 ±2400 mV 的量化步长约为 **0.0732 mV（73.2 µV）**，会损失小幅肌电细节；实时内存中的 float64 波形不受此限制。若后续需要保留24位采集精度，应增加原始浮点文件或BDF等高精度存储，不能把现有EDF报告当作无损数据。

接收端缓存半帧，检查帧尾并重新同步；明确的时间间断或时间回退会结束采集并报告错误，不补造采样点。当前协议没有 CRC、序号、配置或信号来源标识，不能保证发现所有错误，也不能自动识别采样率、PGA或内外部输入模式。长时间运行后 float32 时间戳精度降低，连续性检查也受其限制。

LHE7904 当前本地构建使用 `external.conf`，生成配置关闭内部测试源。板上模式仍取决于实际烧录的固件。本次上位机接入不修改、不烧录固件。

## 独立读取

```python
from emgteach.devices import LHE7904UartDevice

device = LHE7904UartDevice(port="/dev/ttyUSB0")
try:
    device.open()
    samples_mv = device.read(400)  # (400, 1), float64，约100ms
finally:
    device.close()
```

首次硬件验收应检查连续波形、时间轴、停止/重连和录制文件的4000 Hz采样率。模拟串口测试通过不等于真实硬件链路已验收。实时 iEMG/MPF/MF 面板及自动报告导出不属于本次接入。

## 清晰观察波形

- 观察100 Hz正弦信号时，选择 **50 ms** 可看到约5个周期，**100 ms** 可看到约10个周期。
- 使用 **Fit amplitude** 按当前可见数据适配纵轴；幅值变化后可再次点击。显示量程不会改变采样值、PGA或文件物理量程。
- 原始波形、包络及加速度计的时间轴同步。鼠标平移或缩放后，时间窗标签跟随真实可见范围；回放时快捷窗口围绕当前视图中心缩放。
- 录制结束后，Auto开启时优先显示周期细节，关闭时显示整段回放。**Reset scales** 在实时显示时恢复5秒窗口，在回放时恢复整段记录，并重新适配幅值。

## EDF 终端日志

`Invalid char ... no spaces` 可能来自 pyedflib 对带空格的文件头字段的警告。已检查的录制文件中，协议和设备字段可以正确读回；该警告本身不能证明波形损坏。为保留字段语义，不对这些日志作全局屏蔽。

`read -1, less than ... requested` 已复现于多个线程并发读取同一完整EDF的场景，甚至可能返回全零数组而不抛出Python异常。文件读取入口现使用共享锁保护完整的打开、读取、关闭过程。若更新后仍出现该日志，需要继续检查具体文件及其他直接调用pyedflib的路径。

## 实时 Auto 周期观察

LHE7904 单通道默认开启 **Auto**。收到至少0.5秒原始采样并确认稳定周期后，自动选择约5个周期的时间窗：100 Hz约50 ms，50 Hz约100 ms。数据始终实时滚动，最新采样位于右侧。时间窗限制在10 ms到5秒，因此1 kHz显示约10个周期。

Auto只调整原始图的观察量程；上下图横轴继续同步。原始纵轴以零为中心，预留15%余量，幅值增大立即扩展，减小时平缓收缩。检测失败时显示“Detecting cycles…”，持续2秒没有有效周期后恢复5秒窗口。频率提示仅用于观察，不是精密校准读数或肌电分析指标。

点击50/100 ms、Fit amplitude、原始纵轴缩放按钮，或用鼠标缩放/平移，会退出Auto。再次点击Auto可恢复。录制结束后，如果Auto已开启，会在回放中心附近取原始数据识别频率，自动显示约5个周期并适配幅值；Auto关闭时保留整段回放。回放中也可点击Auto，按当前视图中心重新适配；未发现稳定周期时显示整段记录。点击Reset scales恢复整体，再点击Auto可回到周期观察。下一次录制保留本次选择的开关偏好。双通道禁用Auto，继续使用既有的堆叠与手动缩放。
